# PANO-3U 通信协议规范

版本 B / 2026-09

## 1. 板间链路（OBC ↔ CM4 载荷计算机）

- 物理层：UART，115200 8N1，3.3V 电平，经堆栈总线 J1（Pin 13/14）
- 帧结构（HDLC 风格）：

```
[0x7E][CMD:1B][LEN:1B][PAYLOAD:0~255B][CRC16-CCITT:2B][0x7E]
转义: 载荷中出现 0x7E→0x7D 0x5E；0x7D→0x7D 0x5D
```

### 指令表（OBC→CM4）

| CMD | 名称 | 载荷 | 说明 |
|---|---|---|---|
| 0x01 | PING | — | 心跳，CM4 须 1s 内回 ACK |
| 0x02 | TIME_SYNC | uint32 epoch | 时间同步 |
| 0x03 | SHOOT | uint8 burst, uint16 interval_s | 全景拍照（连拍张数/间隔） |
| 0x04 | VIDEO_START | uint16 duration_s, uint8 fps | 开始全景视频 |
| 0x05 | VIDEO_STOP | — | 停止录像 |
| 0x06 | TIMELAPSE | uint16 interval_s, uint16 count | 延时摄影 |
| 0x07 | GET_STATUS | — | 查询载荷状态 |
| 0x08 | FILE_LIST | uint16 offset | 文件清单（分页） |
| 0x09 | FILE_PREP | uint32 file_id | 准备下传某文件（返回分块表） |
| 0x0A | SHUTDOWN | — | 载荷安全关机（OBC 随后断 PAYLOAD_EN） |
| 0x10 | PARAM_SET | key:1B + value:4B | 参数设置（曝光/增益/编码码率等） |

### 应答（CM4→OBC）

| CMD | 名称 | 载荷 |
|---|---|---|
| 0x81 | ACK | 原CMD + status |
| 0x87 | STATUS | 见下 |
| 0x88 | FILE_LIST_RESP | count + [file_id:4B, size:4B, ts:4B]×N |
| 0x89 | FILE_PREP_RESP | file_id, total_chunks:2B, chunk_size:2B, file_crc32:4B |

STATUS 载荷（24B）：mode:1B, cam0_ok:1B, cam1_ok:1B, temp0:int8, temp1:int8, disk_free_mb:uint16, vbat_mv:uint16, shooting:1B, pending_files:uint16, uptime_s:uint32, last_err:1B, reserved:6B

## 2. UHF 下行链路（星→地）

- 物理层：437 MHz，GFSK 9600 bps，AX.25 UI 帧（HDLC 封装由 Si4463+OBC 软件完成）
- AX.25 地址：源=NOCALL-11（星），目的=NOCALL-0（地面），PID=0xF0

### 下行包类型（AX.25 Info 字段首字节为类型）

| 类型 | 名称 | 结构 | 时机 |
|---|---|---|---|
| 0x01 | 信标遥测 | [type][seq:2B][OBC遥测32B][CM4 STATUS 24B][CRC32] | 每 30s 周期性 |
| 0x02 | 文件块 | [type][file_id:4B][chunk_no:2B][total:2B][data:N][CRC32] | 过境时连续发送 |
| 0x03 | 文件清单 | 同 FILE_LIST_RESP | 应地面请求 |
| 0x04 | 事件日志 | [type][ts:4B][code:1B][data:8B] | 异常/模式切换时 |

### 断点续传与选择重传

- 文件分块：每块 200 字节，块内 CRC32 校验；
- 地面站按 file_id 收块，记录已收位图；
- 过境结束时地面站通过上行（AX.25 命令帧，需执照操作）或下一过境首包发送**缺失块清单**（位图压缩），星上补发；
- 单文件最多支持 65535 块（≈13 MB），全景图压缩后约 5 MB ≈ 25000 块，一过境（8 min @9.6kbps 有效吞吐约 400 KB）约 12 个过境传完。

### 上行（地→星）

| CMD | 名称 | 说明 |
|---|---|---|
| 0x21 | REQ_MISSING | file_id + 位图偏移 + 缺失块列表 |
| 0x22 | SET_MODE | 强制模式切换（双重确认） |
| 0x23 | SCHEDULE | 拍摄计划表上传（最多 32 条：[epoch, cmd, param]） |
| 0x24 | PARAM_SET | 同板间 0x10 |

## 3. 错误码

0x00 OK；0x01 相机0故障；0x02 相机1故障；0x03 存储满；0x04 存储I/O错误；0x05 编码器错误；0x06 温度超限；0x07 参数非法；0x08 链路超时
