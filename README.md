## ✨ 任务概览 / Mission

| 项目 | 规格 |
|---|---|
| 构型 | 3U(100×100×340.5 mm),Cal Poly CDS Rev.14,P-POD 兼容 |
| 任务 | 双鱼眼侧面对置 360°×180° 全景成像,输出 5760×2880 |
| 载荷 | 2× Sony IMX477 + M12 鱼眼 f1.4/F2.4 FOV≥195°(等距投影) |
| 视频 | 4K30(CAM0)+ 2.8K30(CAM1),双机硬同步 <1 ms |
| 轨道 | 500 km SSO(i=97.4°),设计寿命 ≥1 年 |
| 数传 | UHF 437 MHz,GFSK 57.6 kbps(裕量 10.7 dB),AX.25/KISS |
| 电源 | 72 片太阳阵 18.4 W BOL,4 通道 MPPT,2S2P 49 Wh |
| 姿态 | B-dot 消旋(17.3°/s→2°/s @2.3 h)+ 磁强计粗定姿 ±5° |
| 质量 | 2.83 kg(含 20% 裕量)| 结构基频 611 Hz | 全 SF≥28 |

## 🚀 快速开始 / Quick Start

- **想看这颗星长什么样** → `03_生产图纸_GB23页/PDF`(23 页)或 `04_三维模型_STEP/装配`
- **想复刻/教学** → `00_包总览/STD-000`(标准对照)→ `REQ-001`(需求)→ `07`(工艺)→ `08`(试验)
- **想学卫星工程** → 从 `SPC-001 设计说明书` 入手,配合 `ANA-001 仿真报告` 与 `TRC-001 追溯矩阵`
- **要发射?** → 完成 `REV-001` 开放项 C1-C6,按 `SAF-001` 对接发射商
